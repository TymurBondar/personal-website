Create `src/components/NavLink.js` — a "use client" component:
- Import `Link` from `next/link` and `usePathname` from `next/navigation`

- Compute `isActive`: use `pathname === '/'` for root href, `pathname.startsWith(href)` for all others — this avoids "/" matching every page
- Active state classes: `text-forest-400 font-semibold border-b-2 border-forest-400 pb-0.5`

Create `src/components/NavMobileMenu.js` — a "use client" component:
- Import `useState` from `react` and `NavLink` from `./NavLink`
- Accept `links` prop (array of `{href, label}` objects)
- State: `const [open, setOpen] = useState(false)`
- Render structure:
  - Outer `<div className="md:hidden">` (hidden on desktop)
  - Hamburger button with `aria-label="Toggle menu"` and three `<span>` bars:
    - Each span: `block w-6 h-0.5 bg-cream-100 transition-all duration-300`
    - When open: first span gets `rotate-45 translate-y-1.5`, middle span gets `opacity-0`, last span gets `-rotate-45 -translate-y-1.5`
    - Middle span has `my-1` for spacing
  - Dropdown panel: `<div className="absolute top-full left-0 right-0 bg-bark-900 flex flex-col gap-4 px-6 py-4 transition-all duration-300 ...">`
    - When open: `opacity-100 translate-y-0`
    - When closed: `opacity-0 -translate-y-2 pointer-events-none`
  - Map `links` to NavLink components, passing `onClick={() => setOpen(false)}` so menu closes on navigation

IMPORTANT: Do NOT use `framer-motion` or `motion` in NavMobileMenu. CSS transitions via Tailwind classes are sufficient for the hamburger and dropdown animations. The `motion` package is only for the hero (Plan 05-02).
