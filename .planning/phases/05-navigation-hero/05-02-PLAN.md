**Step 2: Browse 21st.dev for hero component**

Use the `mcp__magic__21st_magic_component_builder` tool to find a typographic hero component with text animation support. Search query: "typographic hero text animation". The component must:
- Be text-focused (typographic, no heavy imagery)
- Support or be adaptable to word/character stagger animation
- Have CTA button support or be easily extendable with buttons
- Use `motion/react` imports (or be convertible from `framer-motion`)

If the 21st.dev component uses `framer-motion` imports, replace them with `motion/react`:
- `import { motion } from "framer-motion"` -> `import { motion } from "motion/react"`
