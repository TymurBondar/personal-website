## Out of Scope

| Feature | Reason |
|---------|--------|
| Blog / writing section | Thin blog reads worse than no blog; requires sustained content commitment |
| TypeScript migration | Not necessary for portfolio site; keeping JS for simplicity |
| Testing suite | Not priority for static portfolio site |
| OAuth / authentication | Static site, no user accounts |
| CMS (Contentful, Sanity) | Overkill for solo dev with static content |
| Skills progress bars | Meaningless percentages; universally flagged as unprofessional |
| 3D hero / particle effects | Wrong aesthetic for minimal site; hurts performance |
| Preview deploys / branch protection | Essential CI/CD only for v1 |
